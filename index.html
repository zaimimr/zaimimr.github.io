Private household calendar connector

A shared plan, with personal events kept personal.

ZHouse Calendar Source Reader uses read-only Google Calendar access to prepare private daily plans and avoid clashes with household proposals. The shared calendar is the household's existing iCloud calendar.

01

Read selected sources

The connector reads events from calendars a household member has authorized and selected. It does not edit Google Calendar events.

02

Keep sharing explicit

Only a non-private event marked with znz: can be projected to the shared iCloud calendar. The shared entry says “Busy” by default.

03

Ask before scheduling

Training and date proposals wait for household approval before an event is added to the shared iCloud calendar.

Google Calendar access

Read-only, for this household pilot.

Calendar data supports the private functions described here. The public information page has no account sign-in or calendar data.
