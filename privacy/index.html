Privacy policy

ZHouse Calendar Source Reader is a private household pilot. This policy explains its use of Google Calendar data. The connector requests only read-only calendar-list and event access.

Data accessed

For calendars a member authorizes and selects, the connector reads calendar identifiers and event times, titles, visibility, and identifiers within a rolling 14-day planning window. It does not edit or delete Google Calendar events.

How data is used

Event details help prepare a private plan for the calendar owner and avoid clashes with household training and date proposals. A non-private event whose title begins with znz: may have its time projected to the shared iCloud calendar as “Busy”. Unmarked, private, and confidential events are not projected. Source event titles are not shown on the shared calendar by default.

Storage and access

OAuth credentials are held in restricted local secret files on the private household host. Limited plan summaries, projection identifiers, and run records may be kept in its private database and protected backups. The owner's private Slack briefing may include the owner's event titles. Shared iCloud entries expose only the selected event time and the default “Busy” title to household calendar members.

Other uses

Google Calendar data is used only for these household functions. It is not sold, used for advertising, or made available through this public information page.

Revocation and deletion

A member can revoke the connector's Google access in their Google Account at any time. Revocation stops new access; existing private run records and backups are not deleted automatically. To remove those records and the stored credentials, contact the household operator directly. Do not post calendar details in a public GitHub message.

This information page

This static page sets no own cookies and runs no analytics script. GitHub Pages hosts it and may process connection data to serve and protect the site.
